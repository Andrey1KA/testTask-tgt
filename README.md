# Разбор обрыва новичков

Один экран для того, кто ведёт новичка. Он читает задачи Битрикс24 и показывает, на каком шаге маршрута люди сходят в первые 90 дней и кто из текущих новичков молчит слишком долго.

Маршрут один на всех: инструктаж, стажировка, самостоятельная смена, сдача зачёта, успешная адаптация. Ушедшие считаются по строке «Дата ухода» в описании задачи, не по статусу задачи в Битриксе.

## Запуск

Нужны Node.js 22 и входящий вебхук Битрикс24 с доступом к задачам.

```bash
npm install
copy .env.example .env
```

В `.env` укажите базовый адрес вебхука без метода и без слэша на конце:

```text
BITRIX_WEBHOOK_BASE=https://портал.bitrix24.ru/rest/1/код
```

Проверка доступа и локальный экран:

```bash
npm run check-profile
npm run dev
```

Сборка:

```bash
npm run build
npm start
```

Вебхук читается только на сервере. В браузер уходит ссылка на задачу, без секрета.

`DEMO_ACCESS_CODE` в `.env.example` зарезервирован для закрытого демо и на локальном экране не проверяется.

## Откуда цифры

Экран берёт задачи, заголовок которых начинается с `[НОВИЧОК]`. Факты лежат в описании:

```text
Контур: магазин
Дата выхода: 2026-06-20
Последний чек-ин: 2026-07-26
Дата ухода: 2026-08-01
Наставник: директор магазина
Пройдено: Инструктаж; Стажировка
```

Открытый шаг — первый пункт маршрута, которого нет в строке «Пройдено». Молчание ушедшего считается от последнего check-in до даты ухода, а если check-in не было — от даты выхода. У того, кто ещё работает, молчание считается до сегодняшнего дня.

На этом портале метод чеклиста задач недоступен, поэтому шаги записаны строкой «Пройдено», а не пунктами чеклиста. Наставник — тоже строка в описании, не пользователь Битрикс24.

Если портал не ответил или задач новичков нет, экран прямо говорит об этом и показывает `data/fallback-tasks.json`.

## Посев

```bash
npm run seed
```

Скрипт создаёт 18 задач: ушедших и тех, кто ещё в первые 90 дней. Повторный запуск ничего не создаёт, если такие задачи уже есть. Ответственный у всех задач — пользователь вебхука. Задачи не удаляйте ради повторного посева: на бесплатном тарифе счётчик созданных задач не возвращается.

## Проверки

```bash
npm test
```

Тесты проверяют разбор описания и расчёт воронки, бейджей и зоны риска на фиксированную дату.
